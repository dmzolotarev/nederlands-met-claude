# Nederlands met Claude 🇳🇱

Личный репетитор нидерландского на базе [Claude Code](https://claude.com/claude-code). Помнит твой
прогресс между сессиями, ведёт интервальные повторения твоих ошибок, работает с твоим учебником и
готовит к экзаменам (Inburgering A2: Schrijven, KNM).

Открываешь папку, пишешь «Привет, что сегодня?» — получаешь дашборд:

```
🎯 Экзамены: Schrijven через 12 дн. · KNM через 41 дн.
📚 Nederlands in actie: H3 — In Nederland · со мной: indirecte rede ✅
🏫 Курс: группа в H3 · 📝 ДЗ к чт: opdr. 8, 10
🔁 К повторению сегодня: 9 карточек
⚡ Неправильные глаголы: знаю 12 / учу 8 / не трогали 73
🔥 Занятий всего: 9, последнее: вчера
```

## Что нужно
- **Claude Code** — desktop-приложение (вкладка Code), CLI или расширение VS Code / JetBrains.
  Нужна подписка Claude Pro / Max или API-ключ.
- **Git** — чтобы хранить свой прогресс и получать обновления.
- По желанию: **PDF учебника**. Без него тоже работает (по фото страниц или по своей программе).

## Старт за 5 минут
1. Сделай свою копию: на GitHub **Use this template → Create a new repository → Private**
   (там будет твой личный прогресс). Или просто `git clone`.
2. Открой папку в Claude Code.
3. Напиши **«Привет»** — Клод проведёт знакомство (`/start`, ≈ 5 мин): язык объяснений, уровень,
   учебник, курс, экзамены. Уровень не знаешь — сделает тест на 10 минут.
4. Есть PDF учебника — положи в `materiaal/boeken/<учебник>/boek/` (Клод подскажет путь).

## Команды
Команды не обязательны: можно писать обычным языком («давай дальше», «погоняй глаголы»,
«сделаем ДЗ», «вот фото упражнения»).

| Команда | Что делает |
|---|---|
| `/start` | Знакомство и профиль. Потом — правка: `/start экзамен перенесли на 12.03` |
| `/les [N]` | Занятие по главе: теория, упражнения книги, проверка по ключам |
| `/toets [модуль \| cursus \| mock \| niveau]` | Экзамены: задания как на Inburgering, mock на время, тест уровня |
| `/herhaling` | Повторить «созревшие» карточки (интервальные повторения) |
| `/woorden [N]` | Аудит слов главы: что знаешь, что — в повторение |
| `/werkwoorden [n \| hN]` | Тренажёр неправильных глаголов |
| `/spreken [тема]` | Разговорная практика с разбором ошибок |
| `/huiswerk` | ДЗ курса: конспект слайдов урока, задания по одному с проверкой |
| `/ophalen [N]` | Достать словник главы из PDF или с портала учебника |

## Как это устроено
```
CLAUDE.md            правила репетитора (общие)
.claude/commands/    команды выше (общие)
sjablonen/           пустые шаблоны личных файлов
voortgang/           🔒 ТВОЁ: профиль, дашборд, план, колода SRS, логи — создаёт /start
materiaal/
  boeken/            учебники: карта каждой книги (bron.md) + твой PDF и словники (не в git)
  examens/           экзамены: формат, источники, как тренировать
  spiekbriefjes/     шпаргалки по грамматике — 11 тем, A1 → B1
  onregelmatige-werkwoorden.md   справочник 93 неправильных глаголов
```
- **Всё личное — в `voortgang/`.** Ничего про тебя в `CLAUDE.md` нет, поэтому обновления
  харнесса приходят без конфликтов.
- **Твои правила** для репетитора («строже», «без эмодзи», «объясняй через английский») пиши в
  `voortgang/profiel.md`, раздел «Мои правила». Они главнее `CLAUDE.md`.
- **SRS** — интервальные повторения по Лейтнеру: что вспомнил — покажу через 3, 7, 16, 35 дней;
  что забыл — завтра. Карточки заводятся только на твои реальные ошибки.
- **Шпаргалки** растут вместе с тобой: Клод дописывает в конец каждой раздел «🙋 Мои ошибки».

## Учебники
| | Уровень | Материалы |
|---|---|---|
| **Nederlands in gang** (Coutinho, 3-е изд.) | 0 → A2 | портал Coutinho: словник NL–RU, упражнения |
| **Nederlands in actie** (Coutinho, 4-е изд.) | A2 → B1 | твой PDF: словники, ключи к упражнениям |
| **Без учебника** | A1 → B1 | программа из 23 тем, Клод готовит материалы сам |
| **Другой** | | положи PDF и скажи «добавь мой учебник» — Клод соберёт карту по оглавлению |

## Экзамены
Готов пакет **Inburgering A2** (Schrijven — полный формат, KNM — 8 тем). Другой экзамен
(B1, Staatsexamen NT2…) — Клод найдёт формат сам и соберёт пакет с пометкой «не проверено».

## Обновления
```bash
git remote add upstream https://github.com/<автор>/nederlands-met-claude.git
```
```bash
git pull upstream main
```
Твой `voortgang/` обновления не трогают. Не правь `CLAUDE.md` и команды под себя — для этого
есть профиль; иначе при обновлении будут конфликты.

## ⚠️ Авторское право
PDF учебников и всё, что из них извлечено (словники, упражнения), — только для личной учёбы.
Они в `.gitignore` и в репо не попадают. Держи свою копию **приватной**: там твой прогресс.

## Как помочь
Карта нового учебника (`materiaal/boeken/<slug>/bron.md`, без PDF), пакет экзамена
(`materiaal/examens/`), шпаргалка по теме — присылай PR. Образцы форматов — в
`materiaal/boeken/README.md` и `CLAUDE.md`.
