# Шпаргалка: возвратные глаголы (reflexieve werkwoorden, H11)

## Возвратные местоимения
| лицо | мест. | пример (zich voelen) |
|---|---|---|
| ik | **me** (mij) | ik voel **me** goed |
| jij | **je** | jij voelt **je** goed |
| hij/zij/het | **zich** | hij voelt **zich** goed |
| wij | **ons** | wij voelen **ons** goed |
| jullie | **je** | jullie voelen **je** goed |
| zij (мн.) | **zich** | zij voelen **zich** goed |
| u | **u / zich** | u voelt **zich** goed |

🔑 Ключ: **ik→me · hij/zij→zich · wij→ons**. Остальные → *je*.

## Порядок слов
Местоимение — **сразу после спрягаемого глагола (и подлежащего при инверсии)**.
- Ik was **me**. — Я моюсь.
- ⚠️ Обст. впереди → инверсия: **Vandaag voel ik me** goed. (не «Vandaag ik voel»)
- Вопрос → инверсия: **Haast je je?** (первое je = «ты», второе = возвратное). Haasten БЕЗ zijn!
- Разделяемый: Hij **kleedt zich aan** (zich после глагола, приставка aan в конец).

## Частые возвратные глаголы
- zich voelen — чувствовать себя (ik voel me goed / niet lekker)
- zich wassen — мыться
- zich haasten — торопиться
- zich vergissen — ошибаться
- zich herinneren — помнить
- zich aankleden — одеваться (раздел.)
- zich vervelen — скучать

## Perfectum
Вспомогательный **hebben** + местоимение сразу после него:
- Ik **heb me** gewassen. — Я помылся.
- Hij **heeft zich** vergist. — Он ошибся.

## ⚠️ Ловушки
- ❌ «Vandaag **ik voel**…» → ✅ «Vandaag **voel ik** me…» (инверсия!).
- ❌ «**Ben** je … je?» → ✅ «**Haast** je je?» — возвратный глагол спрягается сам, без zijn.
- Не путать местоимение: ik→me, hij→zich, wij→ons.
