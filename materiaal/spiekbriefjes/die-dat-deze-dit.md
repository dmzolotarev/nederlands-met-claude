# Шпаргалка: die / dat / deze / dit (NiG H15)

## Правило (2 оси: близко/далеко × de/het)
|  | этот/эти (близко) | тот/те (далеко) |
|---|---|---|
| **de-слово** (ед.) | **deze** | **die** |
| **het-слово** (ед.) | **dit** | **dat** |
| **мн. число** | **deze** | **die** |

- При существительном род решает: *deze/die auto* (de) · *dit/dat huis* (het) · *deze/die kinderen* (мн.).
- **Самостоятельно** (вместо сущ.) — по роду заменяемого слова:
  *De foto? **Die** is mooi. Het boek? **Dat** is goed.* · *Welke jas? — **Deze** / **Die** daar.*
- **Представление «это есть…» / указание на факт → всегда dit / dat** (род НЕ важен),
  глагол — по числу представляемого: ***Dit** is mijn zus.* · ***Dat zijn** mijn ouders.*
- Целая мысль/ситуация → **dat**: *Is **dat** goed? Ik vind **dat** leuk.*
- 🧠 Приём: подставь артикль — *de* → die/deze, *het* → dit/dat.

## Примеры
- de bus → **Die** kun je nemen. — Его (автобус) можно взять.
- het centrum → **Dat** ligt achter het station. — Он (центр) за вокзалом.
- Ik neem niet **deze**, maar **die**. — Беру не этот, а тот.
- **Dat** is een goed idee. — Это хорошая идея.

## ⚠️ Ловушки
- `foto` = **de** foto → die/deze (не «dat»!).
- Не дефолтить на **dat**: близко → dit; de-слово → die/deze.
- «Это мои туфли» → **Dit zijn** mijn schoenen (не *deze zijn*).
- `deze` → de-слово, `dit` → het-слово (подсказка прямо в тексте задания).

## Связано
- Nederlands in gang: H15 15.4 Demonstratief pronomen.
- Та же логика у относительных местоимений (*de man **die**…, het huis **dat**…*) → NiA H5–H6
  «relatief pronomen».
