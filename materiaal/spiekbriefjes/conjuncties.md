# Шпаргалка: союзы (conjuncties) — NiG H16/18 · NiA H1 1.6

## Две группы — главное это ПОРЯДОК СЛОВ
- **① Сочинительные — обычный порядок (глагол на 2-м месте):** en, maar, want, of, dus.
  *Ik ben moe, **dus** ik **ga** slapen.*
- **② Подчинительные — глагол в КОНЕЦ:** omdat, nadat, voordat, terwijl, zodat, hoewel, als, zodra, toen, wanneer.
  *…, **omdat** ik moe **ben**.*
  Придаточное первым → инверсия в главном: ***Omdat** ik moe ben, **ga** ik slapen.*
- В придаточном с перфектом **ВСЕ** глаголы в конец: *nadat ik alle foto's **heb gezien**.*

## Полная таблица с переводами
### ① Сочинительные (глагол на 2-м месте) — мнемоника 🐱 **MEOWD** (maar · en · of · want · dus)
| NL | RU | Пример |
|----|----|--------|
| en | и | Ik werk **en** ik studeer. |
| maar | но | Het is duur, **maar** ik koop het. |
| want | потому что (причина) | Ik blijf thuis, **want** ik ben ziek. |
| of | или | Koffie **of** thee? |
| dus | поэтому (следствие) | Ik ben moe, **dus** ik ga slapen. |

### ② Подчинительные (глагол в КОНЕЦ)
| NL | RU | Пример |
|----|----|--------|
| omdat | потому что (причина) | …, omdat ik moe **ben**. |
| hoewel | хотя (контраст) | …, hoewel het duur **is**. |
| als | если/когда (наст./буд./повтор) | **Als** het regent, blijf ik thuis. |
| toen | когда (один раз в прошлом) | **Toen** ik klein **was**, … |
| terwijl | в то время как (одновременно) | …, terwijl ik **kookte**. |
| nadat | после того как | **Nadat** ik gegeten **had**, … |
| voordat | до того как | **Voordat** ik ga, … |
| zodra | как только | **Zodra** ik thuis **ben**, … |
| zodat | так чтобы (цель) | …, zodat hij kan **betalen**. |
| dat | что | Ik denk **dat** het goed **is**. |
| wanneer | когда (вопрос/условие) | **Wanneer** kom je? |

## ⚠️ Ловушки
- **want** (причина «потому что», ①) ↔ **dus** (следствие «поэтому», ①).
- **omdat** (причина, ②) ↔ **hoewel** (контраст «хотя», ②).
- **toen** (когда — один раз/период в прошлом: *toen ik klein was*) ↔ **als** (наст./буд./повтор: *als het regent*) ↔ **terwijl** (в то время как — два действия одновременно: *terwijl ik kookte*). Все три ② → глагол в конец.
- **nadat** (после; с «heb/had gedaan») ↔ **voordat** (до).
- Вспом. глагол в придаточном НЕ на 2-м месте: не «nadat ik **heb** … gezien», а «nadat ik … **heb gezien**».
