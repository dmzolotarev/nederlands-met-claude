# Прилагательное: `-e` или без? (adjectief + uitgang)

## Правило
Прилагательное **перед существительным** почти всегда получает **`-e`**.
**Одно исключение:** `een` (или без артикля / `geen`, `elk`, `veel`…) + **het-слово** → **без `-e`**.

```
een + het-слово        → БЕЗ -e     een persoonlijk gevoel
всё остальное          → -e         het persoonlijke gevoel · de persoonlijke spullen
```

Отдельно (другое правило): прилагательное **после** `zijn / worden / vinden` (сказуемое)
— всегда **голое**: *het gevoel is persoonlijk*.

## Примеры
| без `-e` (een + het) | с `-e` |
|---|---|
| een **wetenschappelijk** onderzoek | het **wetenschappelijke** onderzoek |
| een **medisch** centrum | de **medische** zorg |
| een **persoonlijk** gevoel | een **persoonlijke** vraag (de vraag!) |
| een **mooi** huis | een **mooie** leeftijd (de leeftijd!) |

> *Ik had vannacht een **bijzondere** droom.* — `de droom` → `-e`.
> *Dat is een **vervelend** probleem.* — `het probleem` + `een` → без `-e`.

## Алгоритм в две секунды
1. Стоит перед существительным? Нет → голое, конец.
2. Слово `de` или `het`? **de** → `-e`, конец.
3. het-слово: артикль `het`/`dit`/`mijn`/`deze` → `-e`. Артикль `een` (или его нет) → **без `-e`**.

## ⚠️ Ловушки
- **Окончание прилагательного выдаёт род!** Видишь `een mooie ___` → это **de**-слово.
  Видишь `een mooi ___` → **het**-слово. Рабочая подсказка в упражнениях на подстановку.
- `-e` не зависит от числа: во мн.ч. **всегда** `-e` (*mooie huizen*, хотя *het huis*).
- Притяжательные (`mijn`, `zijn`, `haar`) ведут себя как `het`/`de`, а НЕ как `een`:
  *mijn **persoonlijke** gevoel*.
- Не путай с прилагательным-сказуемым: *de film was **goed*** (не «goede»).
