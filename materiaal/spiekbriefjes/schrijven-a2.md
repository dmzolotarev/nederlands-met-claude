# Inburgering A2 Schrijven: каркас заданий

## Правило
Бумага, **4 задания, 40 мин** (~10 мин на задание). Баллы дают за: **все пункты задания** ·
правильные начало и конец · порядок слов · времена · орфографию. Пиши **просто и без ошибок**, это A2.
- **Formulier**: заполнить все поля. Открытое поле — **2–3 полных предложения** (заглавная буква + точка).
- **Briefje** (30–50 слов, цель **40**): *Beste/Hoi Marieke,* → все пункты → *Bedankt!* → **Groetjes,** → имя.
- **E-mail** (50–70): каждый пункт задания = минимум одно предложение. С `u`: *Geachte meneer/mevrouw …,* →
  *Met vriendelijke groet,*. С `je`: *Beste …,* → *Groetjes,*. **u и je не смешивать.**
- **Korte tekst** (60–80): о прошлом → imperfectum/perfectum, неправильные глаголы.

## Готовые формулы
- Просьба: ***Zou** je/u … **willen / kunnen** + инф.?* · *Kun je …?* (НЕ *mogen*)
- Благодарность заранее: *Alvast bedankt!*
- Причина: *…, **omdat** ik meer Nederlands **wil spreken**.* (глагол в конец)
- Время → место: *Ik woon **al drie jaar in Nederland**.*
- Добавить объёма одной деталью: *Zaterdag ben ik weer thuis.* · *Woensdagavond past goed, omdat ik overdag werk.*
- Формальное начало, имя неизвестно: ***Geachte heer/mevrouw,*** (не «Beste medewerker bij…»)
- Перенести встречу: *Zou u mijn afspraak kunnen **verzetten**?* · *Kan ik een nieuwe afspraak **maken**?*
- Когда могу: *Vanaf vrijdag 13 november **kan ik weer** komen.* · Вернусь: *Ik **kom** op 12 november **terug**.*
- Извинение: ***Excuses voor het ongemak.*** · *Het spijt me.* (без «voor deze situatie»)
- Причина: *…, omdat ik deze week **op zakenreis** in het buitenland **ben**.*

## Примеры
- *Ik heb een vraag voor **jou**: **zou je** mijn planten water **willen geven**?*
- *Ik **wil** mijn Nederlands **oefenen**. Ook **wil** ik nieuwe mensen **ontmoeten**.*

## ⚠️ Ловушки (частые)
- *zou je **mogen** …* → **zou je … willen/kunnen** (mogen = разрешение).
- *voor **jouw*** → *voor **jou*** (jouw = «твой»).
- *ik wil … **te** oefenen* → без **te** после модального.
- Нет прощания: *Hartelijk bedankt!* ≠ прощание → добавить **Groetjes,**.
- Языки с заглавной: **Nederlands**, Engels, Russisch.
- Удвоения: **maandag** (aa) · **deurmat** (одна a) · **wanneer** (nn).
- Брать **слова из задания** («water geven»), так экзаменатор сразу видит закрытый пункт.
- Postcode: **1012 AB Amsterdam** (пробел, без запятой). В конце предложения — точка.
- Пункт из двух частей («vraag om een nieuwe afspraak **en** schrijf wanneer je wel kunt») = **два предложения**.
- *Ik **ga** terug* (уеду туда) ≠ *Ik **kom** terug* (вернусь сюда).
- Объектное местоимение сразу после подлежащего: *Zou u **me** … kunnen …* (не «op andere tijd me»).
