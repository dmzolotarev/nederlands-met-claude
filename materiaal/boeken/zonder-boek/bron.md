# Без учебника — программа A1 → B1

Для тех, у кого нет учебника. «Глава» = тема ниже: `/les 9` — тема 9. Объяснения, слова и
упражнения Клод готовит сам; словники тем — в `woordenlijsten/tN.md`.
Порядок — ориентировочный, по типичной последовательности NT2-учебников. Стартовая тема — по
уровню ученика (A2 → с темы 9, B1 → с 17); пропущенное из прошлых уровней — повторять по слабым местам.

## Как вести тему
1. Объяснение (3–6 строк) + 3–4 примера NL + перевод. Есть шпаргалка — опирайся на неё.
2. 10–15 частотных слов, связанных с темой и бытовой ситуацией из колонки «Ситуация».
3. 5–8 упражнений нарастающей сложности: подстановка → трансформация → своё предложение.
4. Мини-диалог или мини-текст (3–5 предложений) с этой грамматикой.
