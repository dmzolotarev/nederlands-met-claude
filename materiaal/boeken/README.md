# Учебники — пакеты

Каждый учебник — папка `materiaal/boeken/<slug>/`:

```
<slug>/
  bron.md            карта учебника (в репо, общая для всех)
  boek/              PDF книги — кладёшь сам          ⚠️ .gitignore
  woordenlijsten/    словники глав (hN.md), /ophalen  ⚠️ .gitignore
  oefeningen/        упражнения с портала, /ophalen   ⚠️ .gitignore
```

PDF и всё, что из книги извлечено, — авторское право издательства: только для личной учёбы,
в публичный репо не попадает. `bron.md` — только наша карта (номера страниц, темы глав).

## Готовые пакеты
| slug | Учебник | Уровень | Материалы |
|---|---|---|---|
| `nederlands-in-gang` | Nederlands in gang, 3-е изд. (Coutinho) | 0 → A2, 18 глав | портал Coutinho: словник NL–RU, gatenteksten |
| `nederlands-in-actie` | Nederlands in actie, 4-е изд. (Coutinho) | A2 → B1, 11 глав | PDF книги: словники, ключи |
| `zonder-boek` | без учебника — своя программа | A1 → B1, 23 темы | Клод готовит сам |

## Добавить свой учебник
Проще всего: положи PDF в `materiaal/boeken/<slug>/boek/` и скажи Клоду «добавь мой учебник» —
он прочитает оглавление и соберёт `bron.md`. Или напиши руками по образцу ниже.
Пакет пригодится другим — пришли PR с одним `bron.md` (без PDF и словников).

## Образец `bron.md`
```markdown
# <Название> — карта учебника

**<Название>**, <издание>, <год> · <авторы> · <издательство> · ISBN … · Уровень **A2 → B1**, N глав.

## PDF
- Файл: `materiaal/boeken/<slug>/boek/<файл>.pdf`, N стр.
- **Сдвиг страниц:** страница книги = странице PDF − 0   ← проверь на оглавлении!
- 🔑 Ключи: стр. … (или «нет»). Показывать только после ответа ученика.

## Как устроена глава
<разделы главы по порядку> · где словник · как размечены слова (актив/пассив)

## Карта глав
| H | Тема | Старт | Грамматика (раздел · стр. · упражнения) | Повторение | Словник |
|---|---|---|---|---|---|

## Как доставать материалы
<из PDF: какие страницы читать · или с портала: URL-шаблоны, что под логином>

## Сайт учебника
<URL, что там есть>
```
