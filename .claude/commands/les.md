---
description: Занятие по главе активного учебника (теория + упражнения + проверка по ключам)
argument-hint: "[номер главы | <slug> N — другой учебник]"
---
Проведи занятие по нидерландскому. Следуй правилам из CLAUDE.md (профиль, SRS, шпаргалки).

Глава: $ARGUMENTS. Пусто → текущая глава из `voortgang/overzicht.md`; если там есть **пробел**
(пропущенное занятие курса) — предложи начать с него. `<slug> N` → глава N другого учебника из
`materiaal/boeken/<slug>/` (напр. пройденного раньше — для повторения базы).

1. Прочитай `voortgang/profiel.md`, `overzicht.md`, `leerplan.md`, карту учебника
   `materiaal/boeken/<slug>/bron.md` и словник `woordenlijsten/hN.md`. Нет словника, но есть PDF →
   сначала `/ophalen N`.
2. Покажи разделы главы. Если ученик ходит на курс — спроси, что уже было на уроке.
   Открой нужные страницы PDF (`Read(pdf, pages="…")`, ≤ 20 стр.; учти сдвиг страниц из `bron.md`).
3. Грамматика: знакомое — кратко + ссылка на шпаргалку из `materiaal/spiekbriefjes/`; новое —
   объясни на языке объяснений с примерами (NL + перевод) и парой мини-заданий.
4. Упражнения: opdrachten книги по одному. Проверяй по ключам (страницы — в `bron.md`),
   ответ показывай **только после ответа ученика**. Добавь 3–5 своих — на слабые места из профиля.
5. Ошибки → карточки в `voortgang/srs.md`. Тема разобрана → шпаргалка.
6. В конце: обнови `overzicht.md`, статус главы в `leerplan.md`, лог `voortgang/sessies/<дата>.md`.

**Без PDF:** попроси фото нужных страниц или работай по своим объяснениям и упражнениям.
**Без учебника (`zonder-boek`):** глава = тема программы из `materiaal/boeken/zonder-boek/bron.md`.
Объяснение, 10–15 слов темы и 5–8 упражнений готовишь сам, словник сохрани в
`materiaal/boeken/zonder-boek/woordenlijsten/tN.md`.
