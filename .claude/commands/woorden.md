description: Аудит слов главы (NL ↔ язык объяснений) из словника; промахи уходят в SRS
argument-hint: "[номер главы | <slug> N | тема, напр. wonen]"
---
Проверь, насколько ученик уже знает слова главы (режим **аудита**, не зубрёжка с нуля).

N = $ARGUMENTS (пусто — текущая глава из `overzicht.md`).
1. Открой словник `materiaal/boeken/<slug>/woordenlijsten/hN.md`. Нет файла → `/ophalen N`.
   Тема вместо главы (напр. `wonen` к KNM) или учебника нет → составь список из 20–25 частотных
   слов темы под уровень ученика и сохрани в `materiaal/boeken/zonder-boek/woordenlijsten/<тема>.md`.
2. Порции по ~10, вперемешку. **Актив** (в словнике отмечен ★) — в обе стороны; для существительных
   требуй de/het, для слов с предлогом — предлог (*benieuwd **naar***). **Пассив** — только NL → перевод.
   Разметки актив/пассив нет → всё как актив.
3. Верно — знает; ошибся/замешкался — карточка в `voortgang/srs.md` (тип `woord` или `de/het`),
   коробка 1, срок завтра.
4. В конце: сводка (знал X из Y) и список ушедших в повторение. Обнови `overzicht.md` и лог сессии.

Пояснения — на языке объяснений; слова и примеры — на нидерландском.
