Подготовь материалы главы. N = $ARGUMENTS. Не указан → текущая глава из `voortgang/overzicht.md`.
Учебник — активный из профиля или `<slug>` из аргумента.

Карта учебника `materiaal/boeken/<slug>/bron.md` говорит, **где** материалы (страницы PDF, URL
портала) и **как** их доставать (раздел «Как доставать материалы»). Следуй ей.

## Из локального PDF (`materiaal/boeken/<slug>/boek/*.pdf`)
1. Прочитай словник главы (страницы — в `bron.md`; учти сдвиг PDF ↔ книга) через `Read(pdf, pages="…")`.
2. Write в `materiaal/boeken/<slug>/woordenlijsten/hN.md`:
   - слова-**актив** (если учебник их выделяет) — таблица NL | перевод (+ de/het для существительных);
   - слова-пассив — коротким списком, если ученик попросит;
   - vaste preposities главы · неправильные глаголы главы (инф. | o.v.t. ед.—мн. | voltooid deelwoord,
     **is** для zijn-глаголов) · трудные слова с примерами.
   Переводы — на языке объяснений ученика.
3. Глаголов главы нет в `materiaal/onregelmatige-werkwoorden.md` → допиши в нужную группу.
4. Отчитайся: сколько слов-актив, сколько глаголов, какие грамматические разделы (стр.).

## С сайта / портала учебника
URL-шаблоны и что открыто — в `bron.md`. Качай через WebFetch (Bash может быть без интернета):
PDF сохраняется в `…/tool-results/` → `Read` постранично → `Write` в
`materiaal/boeken/<slug>/woordenlijsten/` или `oefeningen/`.

## Карты нет (`bron.md` отсутствует)
Сначала построй её по оглавлению PDF (образец — `materiaal/boeken/README.md`), потом достань главу.

Материалы — для личного учебного использования. Папки `boek/`, `woordenlijsten/`, `oefeningen/` — в
`.gitignore`, в публичный репо не попадают.
