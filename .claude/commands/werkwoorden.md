description: Тренажёр неправильных глаголов (o.v.t. + voltooid deelwoord)
argument-hint: "[сколько глаголов, по умолчанию 10 | hN — глаголы главы учебника]"
---
Тренируй неправильные глаголы.

Аргумент: $ARGUMENTS (по умолчанию 10 глаголов; `hN` — список главы N активного учебника).
1. Источники, по порядку: созревшие карточки-глаголы из `voortgang/srs.md` → глаголы текущей главы
   (`materiaal/boeken/<slug>/woordenlijsten/hN.md`, раздел «Onregelmatige werkwoorden») → `учу` из
   `voortgang/werkwoorden.md` → ещё не тронутые из справочника `materiaal/onregelmatige-werkwoorden.md`
   (начинай с группы A — самые частотные).
2. Формат: даю инфинитив (+перевод) → ученик называет **o.v.t.** (ед/мн) и **voltooid deelwoord**
   с hebben/zijn. Иногда наоборот: форма → инфинитив. Иногда — фраза о прошлом:
   *Gisteren ___ ik naar de markt (gaan).*
3. Верно → в `voortgang/werkwoorden.md` статус `знаю` (2-й раз подряд) / карточка SRS +1.
   Ошибка → статус `учу` + карточка (тип `werkwoord`) в `srs.md`: коробка 1, срок завтра.
4. Даты — через `date`. В конце — сводка, обнови счётчик глаголов в `overzicht.md`
   (знаю / учу / не трогали = справочник минус проверенные) и лог.

Всегда показывай полную правильную форму и пример в perfectum: *ik heb gezien*, *hij is gegaan*.
Нового глагола из книги нет в справочнике → допиши его в нужную группу справочника.
