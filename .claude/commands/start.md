Знакомство с учеником и настройка харнесса. Общие правила — в CLAUDE.md.

Аргумент: $ARGUMENTS

## Если `voortgang/profiel.md` уже есть
- Аргумент — правка («поменяй дату экзамена», «теперь я в H5», «новый учебник») → внеси её в
  `profiel.md` и во все зависимые файлы (`overzicht.md`, `leerplan.md`, `examenplan.md`), покажи дашборд.
- Пусто → покажи профиль коротко и спроси, что поменять. **Ничего не перезаписывай молча.**
- `reset` → только после явного «да»: перенеси `voortgang/` в `voortgang/archief/<дата>/` и начни заново.

## Онбординг (профиля нет)
Спрашивай **блоками, по одному блоку за сообщение**, коротко, с вариантами ответа. Не знает — ставь
`?` и иди дальше. Язык первого сообщения — тот, на котором написал ученик.

**Блок 1 — кто ты**
1. Как к тебе обращаться?
2. На каком языке объяснять грамматику? (русский / English / другой)
3. Уровень сейчас: A0 · A1 · A2 · B1 · B2 · «не знаю». И к какому идём?
4. Зачем учишь? (inburgering / работа / учёба / жизнь в NL / …)

**Блок 2 — учебник и курс**
5. Учебник: покажи список из `materiaal/boeken/` (кроме `zonder-boek`) + «другой» + «без учебника».
   Какая глава сейчас? Есть PDF?
6. Ходишь на курс? Название, день занятий, задают ли ДЗ.

**Блок 3 — экзамены и режим**
7. Экзамены: какие модули, даты (или «пока не записан»). Пакеты — список `materiaal/examens/`.
8. Что даётся тяжело? (2–3 пункта или «не знаю — найдём»)
9. Сколько времени на занятия? Тон: дружелюбный с эмодзи / строже / как удобно?

## Уровень «не знаю»
Предложи `/toets niveau` прямо сейчас (≈ 10 мин) или поставь `?` и определи по первым занятиям.

## Учебник
- **Есть в `materiaal/boeken/<slug>/`** → используй его `bron.md`. PDF есть — попроси положить в
  `materiaal/boeken/<slug>/boek/` (путь — в `bron.md`).
- **Другой учебник с PDF** → создай `materiaal/boeken/<slug>/bron.md` по образцу из
  `materiaal/boeken/README.md`: прочитай оглавление (первые 5–15 стр.), найди сдвиг страниц
  PDF ↔ книга, ключи (bijlage/antwoorden), словники глав. Отчитайся, что нашёл, и что не нашёл.
- **Другой учебник без PDF** → попроси фото оглавления, по нему создай `bron.md`.
- **Без учебника** → `materiaal/boeken/zonder-boek/bron.md`: программа A1→B1, стартовая тема —
  по уровню ученика.

## Создай файлы (из `sjablonen/`, заполни ответами)
1. `mkdir -p voortgang/sessies voortgang/cursus voortgang/archief`
2. `voortgang/profiel.md` — все ответы.
3. `voortgang/leerplan.md` — главы активного учебника из `bron.md` (тема · грамматика · стр.).
   Пройденное ученик назвал → ✅; текущая глава → 🔄.
4. `voortgang/examenplan.md` — если есть экзамены: дни до каждого (`date`), разбивка по неделям,
   формат из пакета. Нет экзаменов → одна строка «Экзаменов нет».
5. `voortgang/srs.md` (пустая колода), `voortgang/werkwoorden.md` (пусто),
   `voortgang/overzicht.md` (дашборд; «не трогали» = число глаголов в справочнике).
6. Лог `voortgang/sessies/<сегодня>.md`: «онбординг», что узнали.

## Финал
Покажи дашборд (формат — CLAUDE.md) и меню первого занятия, 2–3 пункта. Экзамен ≤ 30 дней →
первым `/toets <модуль>`. Иначе — `/les <текущая глава>` или `/werkwoorden` для разогрева.
Одной строкой: «Профиль можно поменять в любой момент: `/start <что поменять>`».
